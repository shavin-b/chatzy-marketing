Chatzy FAQs

What devices does Chatzy support?

Chatzy is built for Android. Reply behavior depends on the device, its settings, and whether the messaging app exposes a reply action in its notifications.

Does Chatzy reply to every message?

A supported incoming notification must match an enabled rule for Chatzy to send the reply you saved.

Why does Chatzy need notification access?

Local Mode uses Android notification access to read the incoming message text for matching and to send the configured response through the notification’s reply action.

Does Local Mode need Meta API credentials?

Local Mode uses Android notifications and their reply actions. It runs its keyword matching on the phone and requires no Meta API credentials. Chatzy is an independent product.
